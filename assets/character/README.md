# 立ち絵の置き場所

ここに背景が透明な PNG を置くと、みんなの裁判（アニメ風）の右下にナレーターとして出ます。

- `zundamon.png` … 口を閉じた立ち絵（必須）
- `zundamon_open.png` … 口を開いた立ち絵（あれば声に合わせて口パクします）

PSD で配布されている立ち絵は、無料ソフト（例: YMM4、PSDToolKit、GIMP など）で
「口を閉じた状態」と「口を開いた状態」をそれぞれ PNG に書き出してください。

ファイル名を変える場合は `config.yaml` の `character` を書き換えてください。
配布元の利用規約（クレジット表記・商用利用・収益化の可否など）を必ず確認し、
必要なクレジットを `character.credit` に書いてください。
