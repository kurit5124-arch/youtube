# もしもシリーズ（実話）の決まりごと

## 軸
**「本当にやった人がいる、もしも」**
毎回、実際にそれをやった人・本当に行われた実験で答え合わせをする。
ほかの「もしも」動画（作り話・AIの予想）との違いは「作り話じゃない」こと。

## 毎回そろえる型
| 型 | 内容 |
|---|---|
| ① 主人公は「あなた」 | 「もしも、あなたが〜したら」で始める |
| ② 時間で進む | 1日目 → 1週間 → 1か月… と区切ってテロップを出す |
| ③ 実話で答え合わせ | オープニングで「本当にやった人がいる」と予告し、いちばん驚く結末は後半に |
| ④ 今の自分に返す | 「じゃあ、わたしたちは？」で日常の話に戻す。前の話とつなげられたらつなげる |
| ⑤ 決まった締め | コメントの問いかけ →「次回のもしもは〜」→ チャンネル登録 |

## 決まった言い回し
- 始まり：「もしも、あなたが〜」→「これは、想像の話ではありません」
- 終わり：「次回のもしもは、〜。」

## ルール
- 実話の部分は、出どころをファイルの最後の表に必ず書く。公開前に元の資料で確認する
- 危険なことは「マネしないでください」を入れる
- 長さは5〜6分（読む部分 1,500〜1,800字）
